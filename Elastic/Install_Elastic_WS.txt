HƯỚNG DẪN CÀI ĐẶT & QUẢN LÝ HỆ THỐNG LOGS (ELASTICSEARCH - FILEBEAT - KIBANA)
MÔI TRƯỜNG: WINDOWS SERVICE
================================================================================

Luồng: ASP.NET Core --> Log4Net/Serilog (JSON) --> Filebeat --> Elasticsearch --> Kibana

1. ĐỊA CHỈ THƯ MỤC CÀI ĐẶT
--------------------------------------------------------------------------------
- Elasticsearch: <Folder>\Elastic\elasticsearch-9.4.2
- Filebeat     : <Folder>\Elastic\filebeat-9.4.2-windows-x86_64
- Kibana       : <Folder>\Elastic\kibana-9.4.2


2. LỆNH CÀI ĐẶT WINDOWS SERVICE (YÊU CẦU QUYỀN ADMINISTRATOR)
--------------------------------------------------------------------------------

A. ELASTICSEARCH (Chạy bằng CMD)
   > cd /d D:\Mitalab_Testing\BaseRepo\Elastic\elasticsearch-9.4.2\bin
   > elasticsearch-service.bat install Mitalab_Elasticsearch
   > elasticsearch-service.bat manager (Đổi Startup sang Automatic & chỉnh RAM Heap)
   > elasticsearch-service.bat start

B. FILEBEAT (Chạy bằng PowerShell)
   > cd D:\Mitalab_Testing\BaseRepo\Elastic\filebeat-9.4.2-windows-x86_64
   > Unblock-File .\install-service-filebeat.ps1
   > Set-ExecutionPolicy Unrestricted -Scope Process
   > .\install-service-filebeat.ps1
   > sc.exe config filebeat DisplayName= "_Filebeat"
   > sc.exe description filebeat "Service tu dong ghi log vao ElasticSearch"
   > Set-Service filebeat -StartupType Automatic
   > Start-Service filebeat

C. KIBANA (Chạy bằng PowerShell/CMD - Sử dụng công cụ NSSM)
   - Tải nssm.exe cho vào thư mục kibana-9.4.2\bin
   > cd /d D:\Mitalab_Testing\BaseRepo\Elastic\kibana-9.4.2\bin
   > .\nssm.exe install _Kibana
     (Trỏ Path đến file kibana.bat, đặt Display Name là "_Kibana Service")
   > Set-Service _Kibana -StartupType Automatic
   > Start-Service _Kibana


3. CÁC LỆNH BẢO TRÌ NHANH TRÊN POWERSHELL
--------------------------------------------------------------------------------
- Kiểm tra trạng thái:  Get-Service Mitalab_Elasticsearch, filebeat, _Kibana
- Khởi động lại nhanh:  Restart-Service filebeat
- Xóa service Filebeat: sc.exe delete filebeat
- Xóa service Kibana:   D:\...\kibana-9.4.2\bin\nssm.exe remove _Kibana confirm
- Xóa Elasticsearch:    D:\...\elasticsearch-9.4.2\bin\elasticsearch-service.bat remove
================================================================================
